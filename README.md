# Superstore Sales Dashboard — Tableau

An interactive sales analytics dashboard built in Tableau Public using the classic Superstore dataset (~9,800 rows).

🔗 **[View live interactive dashboard](https://public.tableau.com/app/profile/suzain.suzz/viz/SUPERSTOREDASHBOARD_17883559152970/Dashboard)**

 ![Dashboard Screenshot](screenshots/dashboard-overview.png)

## Overview
This dashboard analyzes sales, profit, and regional performance for a US retail superstore, combining geographic, categorical, and time-series views into a single interactive view.

 ## Key Insights
- **Technology** is the top-performing category by sales, but **Furniture** (specifically the Tables sub-category) is losing money despite steady sales volume — a classic high-revenue/low-profit trap.
- **Copiers, Phones, and Accessories** are the most profitable sub-categories overall.
- Sales show strong **seasonality**, spiking every Q4 (Nov–Dec) across all three categories.
- State-level sales are heavily concentrated in California, New York, and Texas.

## Dashboard Features
- KPI cards for Total Sales (₹2,297,201) and Total Profit (₹286,397)
- Interactive US map showing sales by state
- Monthly sales trend broken out by category
- Sales by Category bar chart
- Profit by Sub-Category (highlighting loss-making segments)
